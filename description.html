◆ Technical description

How AEGIS-PX decides a frame has gone wrong

A pipeline description, the data it was validated against, and a lab where you can degrade the input yourself and watch confidence refuse to move.

The pipeline, end to end

Five stages. Nothing in this chain asks the detector how confident it is.

  1. 1

    Frame in

    A single RGB frame from dashcam video, or a rendered CARLA frame.

  2. 2

    Detect

    A standard object detector runs unchanged and produces boxes plus its usual confidence scores.

  3. 3

    Extract

    Activations are tapped from intermediate convolutional layers while the forward pass runs.

  4. 4

    Predict

    A lightweight classifier pools those activations into one failure likelihood for this frame.

  5. 5

    Respond

    The mode-aware response layer picks a fallback appropriate to the current autonomy level.

▲ Response layer

Mode-aware fallbacks

The same risk score means two different things depending on whether a human is available to receive it.

LEVEL 2–3 · DRIVER HANDBACK

Human available

Hand control back

  1. 01 Risk crosses the escalation threshold.
  2. 02 Audible + haptic takeover request, with the reason shown.
  3. 03 Time-to-handover window, escalating in urgency.
  4. 04 If nobody responds → controlled minimum-risk stop.

LEVEL 4–5 · SAFE DEGRADATION

No human

Degrade safely, alone

  1. 01 Reduce speed into an envelope where stopping distance still fits visibility.
  2. 02 Reweight sensors — down-weight the degraded camera, up-weight radar/lidar.
  3. 03 Replan toward the shoulder rather than stopping in a live lane.
  4. 04 Execute a minimal-risk stop and report the event.
