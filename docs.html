How this site is built

Five static HTML pages, Tailwind from a CDN, Three.js for the hero, and no build step anywhere. Every page opens by double-clicking it.

Run it

Option A — double-click index.html. It works. Everything the page needs is either inline, a local file, or an https URL with permissive CORS.

Option B — serve it, which gives you caching and a normal http://localhost origin: 

npx serve .        # then open http://localhost:4173

You need to be online for the CDN assets (Tailwind, Three.js, GSAP, Lenis, Google Fonts). If a CDN is blocked the pages still render — you lose the styling or the animation, not the content.

File structure

One folder, no nesting to learn. Pages link to each other with plain <a href> tags — there is no router, so each file stands on its own.

The 3D import map

Three.js is loaded with an import map so every add-on resolves against the same pinned version — a mismatch here is the classic "module not found" failure: 

<script type="importmap">
{
  "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.169.0/examples/jsm/"
  }
}
</script>

Styling & colour

The palette lives in two places that must agree: the @theme block in each page's <head> (so Tailwind can generate bg-ink, text-sensor and friends) and :root in assets/css/base.css (so components and the shaders can use var(--sensor)).

Colour tokens and their intended meaning
TokenHexMeans
--ink#06090FPage background
--surface#0D141DCards and panels
--fg#E9EFF5Primary text (17.4:1 on ink)
--muted#9DAAB8Secondary text (8.4:1 on ink)
--sensor#2FE6D6The AEGIS layer, healthy signal
--alert#FFB020Warning, keyboard focus ring
--fail#FF5A6EFailure, intervention
--safe#5BE49BNominal, safe degradation

To retint the whole site, change those eight values in both places and the 3D scene updates too — the hero reads the same hexes.

Accessibility (WCAG 2.1 AA)

CONTRAST

Body text 8.4:1 and headings 17.4:1 against the background; every accent colour used for text clears 4.5:1 (the lowest is the red at 6.6:1).

KEYBOARD

Skip link is the first tab stop, focus rings are 3px amber with an offset, the mobile menu closes on Esc and restores focus, touch targets are at least 44px.

NOT COLOUR ALONE

Every status carries a glyph and a word as well as a hue, and the current nav page is marked with aria-current plus a dot plus heavier weight.

MOTION

prefers-reduced-motion stops the camera, freezes the particles, disables smooth scroll and the cursor glow, and shows the 3D scene as a single still that still tells the story.

Canvas elements have role="img" with an aria-label or aria-describedby describing what they show, the lab's readouts are announced through one polite live region, and decorative SVGs are aria-hidden.

Replacing the image placeholders

Every placeholder is a real file, so nothing ever renders as a broken image. To swap one in:

  1. Put your image in assets/images/ — overwriting the SVG or using a new filename.
  2. Keep the width and height attributes roughly right so the layout does not jump while it loads.
  3. Update alt to describe what the picture actually shows. If it is purely decorative, use alt="".
  4. Real photos: compress them (WebP or AVIF) and keep loading="lazy" on anything below the fold.
